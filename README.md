# 🏋️‍♂️ FitLife - Консольный фитнес-бот

Консольное приложение, которое помогает пользователям следить за здоровьем.

## 📋 Возможности

- Приветствие пользователя
- Запрос имени и возраста
- Расчёт индекса массы тела (ИМТ)
- Рекомендация по потреблению воды
